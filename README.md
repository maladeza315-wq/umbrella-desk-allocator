# Umbrella Capital Desk

Build a premium dark landing page and treasury dashboard for a project called “Umbrella Capital”, an on-chain community treasury on Robinhood Chain.

The exact slogan is:

“When it rains, we allocate.”

This slogan must remain exactly identical everywhere: same words, capitalization, punctuation, and spacing. Do not translate, paraphrase, shorten, or replace it.

Use the attached Umbrella Capital image as the visual reference for the brand identity. Preserve the core visual language:

- Black background

- Bright emerald green

- White and green umbrella logo

- Clean corporate typography

- Minimal stealth-corporation aesthetic

- High-end institutional capital desk feeling

- Strong contrast and subtle green glow

- No cartoon style

- No NFT marketplace aesthetic

- No generic DeFi farming appearance

Core narrative:

Umbrella Capital is an on-chain treasury for Robinhood Chain. It acts as a “capital umbrella”, bringing ETH and tokenized stocks such as NVDA, TSLA, and AAPL under one unified canopy.

When the market rains — volatility, meme rotations, panic, and dumps — the capital desk allocates instead of panicking.

The product is a community treasury/vault. Trading fees replenish the canopy, while treasury capital can be allocated across ETH, stock tokens, and reserves.

Important positioning:

- This is a treasury and capital-allocation product, not an NFT minting project.

- Do not use NFT language.

- Do not advertise guaranteed profits, fixed returns, APY, passive income, or risk-free yield.

- The promise should remain soft and conceptual: diversified exposure “under the umbrella”.

- The interface should feel like a serious institutional capital desk, not a casino or meme coin website.

Create the following sections:

1. Hero section

Display the Umbrella Capital logo prominently.

Headline:

“When it rains, we allocate.”

Supporting text:

“An on-chain treasury for ETH, tokenized equities, and strategic capital allocation on Robinhood Chain.”

Primary button:

“Explore the Treasury”

Secondary button:

“View Allocations”

Add a small network badge:

“Powered by Robinhood Chain”

2. Treasury dashboard

Create a polished dashboard card with realistic demo data clearly labeled as “Demo Data” unless connected to real contracts.

Include:

- Total Treasury Value

- ETH Allocation

- NVDA Allocation

- TSLA Allocation

- AAPL Allocation

- Stable Reserve

- Trade Fees Collected

- Treasury Coverage

Use a clean donut chart or allocation chart showing the portfolio under one umbrella/canopy.

Add a visual “Canopy Strength” or “Treasury Coverage” meter showing how fees and reserves replenish the treasury.

3. Market conditions panel

Create a section called “The Desk Is Watching”.

Show market conditions such as:

- Volatility

- Meme Activity

- Market Sentiment

- ETH Momentum

- Equity Token Flow

Use elegant indicators and subtle animations. Keep the tone calm and analytical.

Include the line:

“When the market rains, the desk stays deliberate.”

4. How the umbrella works

Create three steps:

Step 01 — Fees Fill the Canopy

“Trading activity contributes fees to the community treasury.”

Step 02 — The Desk Allocates

“Capital can be distributed across ETH, tokenized equities, and reserves according to market conditions.”

Step 03 — The Community Sees the Structure

“Transparent treasury data gives the community a clear view of what sits under the umbrella.”

5. Asset allocation section

Create cards for:

- ETH

- NVDA

- TSLA

- AAPL

- Reserve

Each card should show:

- Asset symbol

- Allocation percentage

- Current value

- Small trend indicator

- “Under the Umbrella” label

Use mock data only if no blockchain integration exists. Make it easy to replace the mock data with real Robinhood Chain contract data later.

6. Brand manifesto section

Use this copy:

“Markets change. Narratives rotate. Volatility arrives without warning.

Umbrella Capital is built around a simple idea: capital should have structure when conditions become uncertain.

One canopy. Multiple assets. A desk that allocates instead of panicking.”

7. Community treasury section

Add a dark green-highlighted callout:

“Capital under one canopy.”

Include:

- Transparent allocations

- On-chain treasury visibility

- Community-focused structure

- ETH and tokenized equity exposure

- Dynamic allocation narrative

8. Footer

Include:

- Umbrella Capital logo

- Robinhood Chain badge

- Links: Treasury, Allocations, How It Works, Community

- Social links placeholders for X and Discord

- Risk disclaimer

Risk disclaimer:

“Umbrella Capital is an experimental on-chain treasury concept. Digital assets and tokenized assets involve significant risk, including loss of value. Nothing on this website is financial advice, a guarantee of returns, or an offer to buy or sell securities. Treasury data shown in demo mode is illustrative only.”

Design requirements:

- Fully responsive on desktop and mobile

- Use modern React components

- Use Tailwind CSS

- Add subtle premium animations on scroll

- Add smooth hover states

- Use glassmorphism only lightly

- Use emerald green as the main accent color

- Keep the layout spacious and institutional

- Use clean charts and dashboard cards

- Avoid excessive gradients, excessive glow, cartoon illustrations, NFT imagery, coins, rockets, or casino visuals

- Maintain a sophisticated “stealth capital corporation” atmosphere

- Make the exact slogan “When it rains, we allocate.” the central identity of the entire website

If wallet connection is implemented, add a “Connect Wallet” button for Robinhood Chain. Do not create fake transactions or fake blockchain confirmations. If no smart contract is connected, clearly label all figures as demo data.
